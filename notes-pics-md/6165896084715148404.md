# Parallel Operation of Single-Phase Transformers

Transformers are connected in parallel when the load demand exceeds the rating of one transformer, or when supply continuity and flexible capacity are needed.

```text
      Supply bus                    Load bus
          │                            │
      ┌───┴───┐                    ┌───┴───┐
      │  T₁   ├────────────────────┤ Load  │
      └───────┘                    └───────┘
      ┌───────┐
      │  T₂   ├────────────────────
      └───────┘
```

## Conditions for parallel operation

For single-phase transformers, the essential conditions are:

1. Same polarity.
2. Same voltage ratio, or equal secondary no-load voltages.
3. Equal percentage impedance, or closely matched values.
4. Similar impedance angle, or similar \(X/R\) ratio, for proper load sharing.

For three-phase transformers, the following must also agree:

5. Same phase sequence.
6. Same phase displacement, or compatible vector group.

If the voltage ratios differ, the secondary no-load voltages are unequal. This produces undesirable circulating current even with no external load.
