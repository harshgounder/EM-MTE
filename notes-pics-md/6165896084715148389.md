# Transformer Copper Loss, Continued

## Full-load copper loss of the 50 kVA transformer

The previous page found:

\[
R_{eq1}=7.05\,\Omega, \qquad R_{eq2}=0.017625\,\Omega
\]

### Using primary-referred quantities

\[
I_1=\frac{50\times10^3}{4400}=11.36\ \text{A}\quad\text{(rounded)}
\]

\[
P_{cu}=I_1^2R_{eq1}=11.36^2(7.05)=909.80\ \text{W}
\]

### Using secondary-referred quantities

\[
I_2=\frac{50\times10^3}{220}=227.27\ \text{A}
\]

\[
P_{cu}=I_2^2R_{eq2}=227.27^2(0.017625)=910.38\ \text{W}
\]

The small difference arises because the primary current was rounded before squaring. With unrounded currents, both sides give \(910.38\,\text{W}\).
